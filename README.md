# MERN Authentication System

Application full-stack d’authentification développée avec la stack **MERN (MongoDB, Express.js, React, Node.js)**.

---

## Description

Ce projet est un système d’authentification complet permettant aux utilisateurs de s’inscrire, se connecter et gérer leur compte de manière sécurisée.

Il inclut la vérification d’email, la réinitialisation de mot de passe et la protection des routes.


## Fonctionnalités

- Inscription et connexion utilisateur
- Vérification d’email
- Réinitialisation de mot de passe
- Déconnexion sécurisée
- Protection des routes privées
- Authentification via JWT


## Technologies utilisées

- React
- Node.js
- Express.js
- MongoDB
- JWT
- bcryptjs
- Nodemailer


## Structure du projet

- frontend : interface utilisateur (React)
- backend : API serveur (Node.js / Express)
- database : MongoDB


## Installation

### Backend
cd backend
npm install
npm run dev

### Frontend
cd backend
npm install
npm run dev
